# Data dictionary — house_prices.csv

Synthetic data for a fictional Indian city, generated by `generate_data.py` (seed 42). 1,500 unique houses plus
25 duplicated rows added on purpose. Licence: created for this course; free to use and share.

| Column | Type | Description | Values / range | Missing |
|---|---|---|---|---|
| `house_id` | integer | Row identifier. Not a feature. | 1–1500 | none |
| `locality` | category | Neighbourhood | Green Park, Lake View, Tech City, Riverside, Hill Top, Market Area, Old Town, New Colony | none |
| `area_sqft` | number | Built-up area in square feet | 350–4,200 | 13 rows |
| `bedrooms` | integer | Number of bedrooms | 1–5 | none |
| `bathrooms` | integer | Number of bathrooms | 1–5 | none |
| `age_years` | number | Age of the building in years | 0–35 | 20 rows |
| `distance_to_metro_km` | number | Distance to nearest metro station | 0.2–15 km | 10 rows |
| `floor` | integer | Floor number (0 = ground floor) | 0–20 | none |
| `parking` | category | Covered parking available | Yes, No | none |
| `furnishing` | category | Furnishing level | Unfurnished, Semi-Furnished, Fully-Furnished | 17 rows |
| **`price_lakhs`** | number | **Target.** Selling price in lakh rupees (1 lakh = ₹1,00,000) | about 17–236 | none |

## How prices were generated

`price ≈ area × locality rate per sq ft × age discount × metro-distance discount × parking bonus × furnishing bonus
× floor bonus + ₹1.5 lakh per bathroom`, multiplied by random noise of about ±8%. Knowing this lets you check whether
the model learned sensible patterns (for example, that Green Park is the most expensive locality).

Missing counts above include the duplicated rows.
